# Skill Builder — Process Index

Each process is one way this skill runs, chosen by `strategy.md`. Load `references/skill-anatomy.md` and `references/writing-rules.md` before running any of them. The processes assume both are loaded and carry only the steps for that path.

- **build-simple-skill**: turn a one-path task into a single SKILL.md. The five parts: pick one job, list the steps, define what it can use, specify the output, test and refine. Best for procedures, checklists, reports, anything a new teammate could follow from written steps.
- **build-complex-skill**: turn a many-path task into a SKILL.md, a strategy doc, and one process file per path. The six steps: pick one job, list the processes, create the strategy doc, define what it can use, specify the output, test and refine. Best for judgment work where an experienced person chooses an approach before starting.
- **improve-existing-skill**: take a skill that exists and is not working, find which layer is failing, and fix that layer. Best when the person says the skill fires at the wrong time, picks the wrong approach, skips steps, or produces the wrong shape.
